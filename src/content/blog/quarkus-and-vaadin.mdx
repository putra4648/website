## Why Quarkus + Vaadin? 

As a fullstack engineer, I think this is a good combination for building a web application quickly and efficiently. Especially in both frontend and backend, we can use the same language, which is Java. And it is a framework that can help us to build a web application quickly and efficiently.

Quarkus is a Java framework that can help us to build a web application quickly and efficiently. Vaadin is a framework that can help us to build a web application quickly and efficiently.
Same as using Spring Boot and Thymeleaf. But this time I want to try Quarkus and Vaadin. You can build a web application with low resource usage. 

Styling in Vaadin is not really flexible like other CSS framework, but it is easy to use. If you already familiar with Java AWT or Swing, then you will be familiar with Vaadin.
