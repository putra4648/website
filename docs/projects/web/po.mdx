Purchase Order System is a standalone web application that will connect with third party applications.

Features:
- Master Data (Item, Supplier)
- Approval wokflow system
- Send notification items by email
- Department budget control
- Price quotation of goods between suppliers
- Inventory consumable
- Data can be exported to Spreadsheet document
