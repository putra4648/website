## Project Information
An application used to monitor requests for goods from the warehouse to logistics. 
Features:
- Master Data (User, Material)
- Validation of goods to be requested by the user with QR
- Re-validation process for goods that have been requested by other users either in full or only partially
- Data results can be exported in a Spreadsheet document

## Techstack
- Springboot
- PostgreSQL
- Bootstrap
- jQuery
